Core System Capabilities

Built to satisfy course CS23332 requirements combining rigorous Object-Oriented Programming with robust DBMS transactions.

Pure Polymorphic OOP

Full-Time, Part-Time, and Contract models inherit from abstract Employee. Runtime polymorphism handles calculation and database persistence with zero instanceof checks.

Itemized Payslips

On-demand payslip generation with component breakdown (Basic, HRA, DA, PF or Hours × Rate), plus overloaded methods for percentage and fixed bonuses.

Atomic Transactions

Monthly payroll execution is encapsulated in a single all-or-nothing JDBC transaction. Duplicate monthly runs trigger an immediate rollback with zero partial records.

Departmental Raise Engine

Invokes MySQL stored procedure sp_give_raise using a SQL cursor and NOT FOUND handler to iterate and adjust salaries departmental-wide.

Automatic Audit Trigger

Database-level AFTER UPDATE trigger trg_basic_audit logs old and new basic salaries to salary_audit whenever an employee's salary changes.

Real-time MySQL Persistence

All operations write directly to MySQL through PreparedStatement queries. No local state or memory caching: data persists reliably across server restarts.

Salary Calculation Formulas

Deterministic business logic implemented identically in Java and MySQL stored functions.
